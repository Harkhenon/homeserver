# Homeserver

Panel de gestion de serveur web / hébergement.

Front : React + Mantine UI + SASS. Back : NodeJS (Express), modules séparés (Apache, Bind9, PHP, Node...).

- `assets/logo-mark-only.svg` — icône seule, adaptée aux favicons et à la barre latérale
